# McMMO x Discord

This is a simple paper plugin that makes a bridge between McMMO and DiscordSRV, allowing notifications when players level up.

## Permissions

| Permnode                      | default | description                                         |
|-------------------------------|---------|-----------------------------------------------------|
| `mcmmonotifier.do_not_notify` | false   | Hides notifications for players with this permnode. |
| `mcmmonotifier.reload`        | op      | Allows the player to reload the configuration file. |
